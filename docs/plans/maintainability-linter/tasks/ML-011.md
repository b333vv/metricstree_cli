## Implementation sequence

1. Wire configured sourceRoots and classpath into separate before/after AnalysisRequests using snapshot-rebased roots. Analyze all configured Java context; filter findings only afterward.
2. Hash classpath files/directories and verify they are unchanged through the run. Resolve config-relative vs CLI-relative paths exactly once; reject missing roots/entries instead of dropping them.
3. Detect changed known build descriptors/lockfiles from the full Git change manifest, not only Java paths; semantic comparison becomes partial with classpath-version-unverified.
4. Keep exclusions/roles out of resolver context unless they explicitly remove analysis input; report when excluded dependency facts make a global measurement unavailable.
5. Attribute resolution/bulk diagnostics conservatively per comparison contract and preserve before/current origin in issues.
