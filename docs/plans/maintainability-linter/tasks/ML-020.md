## Implementation sequence

1. Implement the v2 envelope, summary counters and nullable comparison; use one gate/detect projection. Keep legacy data on legacy adapters.
2. Pin field ordering and enum spelling via CliObjectMapper; export finite numeric evidence as numbers, absent as null/omitted per schema. Do not reuse stringified analyze metric maps.
3. Store active/existing/suppressed/baseline dispositions and resolved findings distinctly, with evaluation issues independent of findings.
4. Add -o - stdout and --json-output PATH sidecar support without mixing verdict/error text. Render both from one report/analysis. Reject colliding paths; preserve atomic output.
5. Add schema checks using the existing test schema approach extended only for keywords used; negative tests prove malformed output is rejected.
