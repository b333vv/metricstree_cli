## Implementation sequence

1. Implement ordered full-regex path matching and documented defaults; classify logical repository paths once before rule applicability checks.
2. Add explicit role overrides without inferring DTO from names or annotations. Preserve unknown role and empty-list behavior.
3. Apply applicable roles before condition evaluation and record not-applicable counts; excluded files record exclusions, not clean measurements.
4. Keep dependency context available when a role is not checked; role filtering must not remove classes from semantic resolution.
5. Correct gate exclusions that depend on temporary paths by mapping logical FQCN/path consistently. Do not change unrelated analyze/validate exclusion behavior without a regression case.
