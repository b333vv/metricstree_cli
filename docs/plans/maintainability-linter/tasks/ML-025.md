## Implementation sequence

1. Implement separate format and read/write flags; never reinterpret legacy BaselineFile.
   Export mode evaluates all current applicable entities even on an empty diff; it bypasses the
   normal no-change fast path. Required incomplete checks prevent export; optional unavailable
   entries are omitted with explicit warning/count. Export does not accept debt in the same run.
2. Write complete current matches with evidence/reason via atomic creation/replacement and explicit overwrite flag; reject read+write together.
3. Validate schema, rule versions and effective-policy digest. No auto-refresh when policy changes.
4. Compare current evidence against both Git base and accepted baseline; significant worsening against either is one actionable finding. Preserve accepted debt and stale entries.
5. Support exact file-move mapping; no fuzzy matching across renamed methods/packages.
