## Implementation sequence

1. Implement the three modes and default worktree exactly as the comparison table specifies. Resolve HEAD/base only once.
2. Require one merge base and retain full SHAs plus requested-ref text in ComparisonPlan. Use that SHA for both old manifest and content.
3. Build after manifests from HEAD tree, stage-0 index, or working inventory depending on mode; combine committed branch changes with local/index state for staged/worktree.
4. Detect unmerged index for staged/worktree; committed mode ignores dirty/unmerged local index because it uses only object trees. The comparison contract specifies this exception.
5. Keep planner pure relative to source writes; reject unsupported modes and missing ancestry with useful errors.
