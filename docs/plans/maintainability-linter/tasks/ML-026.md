## Implementation sequence

1. Centralize exact dedup key and deterministic sorting in one pure utility used before all adapters.
2. Merge repeated evidence deterministically for same rule/version/entity, preserving locations/reasons; never merge different rule IDs into one JSON finding.
3. Count findings, entities, blocking, suppressed, baseline-accepted, existing and resolved from explicit dispositions; test disjoint disposition counts sum correctly.
4. Human output groups entities with separate rule bullets; evaluation export includes duplicate-group identity for overlapping conceptual findings.
5. Report format must not change verdict, counts or selected findings.
