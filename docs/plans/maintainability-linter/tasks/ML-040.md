## Implementation sequence

1. Check ML-031 measured bottleneck; record evidence-based deferral if benefit is not measurable.
2. Cache whole-snapshot raw measurements with every documented input in the key; never cache final policy verdict.
3. Add cache-dir/no-cache flags, versioned checksummed entries, atomic writes and bounded oldest-entry eviction only within owned cache root.
4. Failed/incomplete analyses are not cached; corrupt entries are misses; rebase logical paths on load.
5. Compare cached/uncached findings exactly except explicit telemetry and benchmark cold/hit/miss plus disk/memory.
6. Separate before/after keys; all source/dependency context changes invalidate.
