## Implementation sequence

1. Derive one metricsVersion property with a dev fallback; generate runtime resource consumed by ToolVersion, --version and JSON/SARIF.
2. Package JAR and launcher distributions with licenses/checksums; retain library coordinates and Java 17 compatibility.
3. Test an unpacked artifact in a fresh consumer repo without Gradle, source checkout or IntelliJ SDK.
4. Prepare tag-triggered workflow running ./gradlew check and building assets/checksums. Verify official upstream action versions/SHAs at implementation time.
5. Document artifact names and verification. Creating tags/pushing/publishing is not part of this implementation task.
