## Implementation sequence

1. Add --history-days positive integer, disabled by default; window ends at resolved HEAD committer time.
2. NUL-safe nonmerge history/explicit rename chains count commits touching a file.
3. Incomplete/shallow history yields unavailable rank; static finding validity remains independent.
4. Sort blocking/severity first, then touch count and old tie-breakers; show count/window/provenance.
5. Evaluate whether ordering helps maintainers; never call churn defect probability.
