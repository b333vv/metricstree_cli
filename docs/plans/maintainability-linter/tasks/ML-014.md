## Implementation sequence

1. Encode the five contract rules, stable IDs/version, metadata, inputs, roles and worsening descriptors as typed data. Use a small named predicate enum for the five fixed worsening formulas, not arbitrary executable expressions.
2. Parse maintainability settings through ConfigLoader's YAML/JSON facade; no extra ObjectMapper. Add nested configuration validation and exact origin/key errors.
3. Implement enabledRules replacement semantics, per-rule complete limits-map replacement, role/mode overrides and maturity restrictions.
4. Compute policy digest from sorted normalized effective data and semantic versions; exclude report format and runtime paths.
5. Add short rule docs under docs/rules/ with evidence, counterexamples and candidate-status explanation; runtime documentationPath is a stable relative path until a verified published URL exists.
