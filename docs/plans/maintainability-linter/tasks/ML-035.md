## Implementation sequence

1. Add seven typed edge kinds at existing extraction/resolution sites; preserve old snapshot constructors.
2. Record source/target type, range, owning method and resolution status; unused imports are not edges.
3. Deduplicate witnesses and sort; cap source examples at 1000 per class with omitted count, but preserve complete unique graph edges for reachability.
4. Build graph once from analyzed-class snapshots; no per-rule parsing or AST retention.
5. Keep old metric/report behavior unless graph evidence requested; add requirements metadata.
