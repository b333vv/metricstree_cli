## Implementation sequence

1. Implement fields/enums from the findings contract using immutable records and copied collections; represent location with logical path and range, not a temporary core SourceLocation path.
2. Define separate finding completeness, lifecycle and disposition; do not reuse excess-ratio Severity for new rule severity.
3. Implement canonical entity-key rendering/parsing and fingerprint array encoding via the shared CLI mapper with deterministic escaping.
4. Add exact-FQCN/signature move matching and previousFingerprint; ambiguous duplicate entity keys yield an evaluation issue instead of arbitrary overwriting.
5. Keep these types internal to CLI initially; do not migrate all legacy reports or export a public API.
