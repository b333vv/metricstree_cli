## Implementation sequence

1. Render rule ID/title, logical path:line, entity identity, lifecycle, before/after conditions, completeness, remediation and documentation link from the common report.
2. Group by entity without collapsing distinct rule evidence. Default to 20 active findings in compact output; show omitted count and keep blocking entries first.
3. Display evaluation issues and suppression/baseline counts even with no active findings. HTML filters must not drop report data.
4. Escape HTML/Markdown source-derived strings; no remote scripts/network assets. Relative documentation links remain honest until hosted docs exist.
5. Adapters consume findings, never recompute policy or severity.
