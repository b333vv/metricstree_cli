## Implementation sequence

1. Build AutoCloseable snapshots from plan manifests in owned temporary roots; write Java bytes using preserved repository-relative layout. Keep a logical path map used by all reports.
2. Snapshot all Java context, not only changed paths. For worktree include nonignored untracked files and retain tracked files even if an ignore rule now matches them.
3. Compute stable content digest from sorted path/content hashes. Recheck working inventory and file content at the end through an explicit verifyUnchanged method; do not let temp paths enter hashes.
4. Reject path traversal; do not follow symlinks or gitlinks. Represent selected unsupported Java inputs as issues for ML-008.
5. Guarantee cleanup on close and on partial construction failure. Never remove outside the owned temp root.
