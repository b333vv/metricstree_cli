## Implementation sequence

1. Collapse internal edges to package vertices; ignore same-package/external cycle edges.
2. Deterministic SCC indexing and sorted BFS provide shortest witnesses for new edges whose targets reach their sources.
3. Compare exact before/current edge sets; detect new cycles inside an old SCC as well as newly cyclic components.
4. Emit MT-A001 per closing edge with stable edge fingerprint/source witnesses. Display at most 20 path edges with omitted count, keeping full internal graph.
5. Partial resolution remains experimental/incomplete; missing edges never prove no cycle.
