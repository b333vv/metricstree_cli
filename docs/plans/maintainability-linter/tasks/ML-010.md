## Implementation sequence

1. Add AnalysisExecution enum and backward-compatible AnalysisOptions constructors/withExecution method. Existing library callers retain parallel behavior; gate defaults to ordered execution until benchmarks support an alternative.
2. Ordered mode visits sorted source files/classes using one worker and a fresh analysis-local solver. Avoid static shared new caches; preserve resource cleanup and bounded AST lifetime.
3. Add a public synthetic semantic fixture with cross-file generics/inheritance and unresolved symbols; run both ordered and parallel variants repeatedly and compare metric values/diagnostic identities with deterministic ordering.
4. Run 20 repetitions in the bounded regression fixture. If semantic variation persists, record exact differences and leave semantic rules advisory; do not assert DEBT-11 resolved without reproducing its historical case or equivalent failure evidence.
5. Prove syntax-only verdict/evidence stability across modes and temp locations; expose execution mode in analysis metadata.
